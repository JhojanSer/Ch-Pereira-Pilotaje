# CHP Pilotaje — Construcción de APK

## Proyecto

CH Pereira y Cía SAS

Aplicación:
CHP Pilotaje

## Objetivo

Convertir la aplicación web de gestión de pilotaje en:

1. Aplicación web.
2. PWA instalable.
3. Aplicación Android APK.

## Arquitectura

La aplicación utiliza:

- HTML
- React
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- Chart.js
- Service Worker
- Web App Manifest

## Etapas

### Etapa 1
PWA básica.

### Etapa 2
Instalación en Android.

### Etapa 3
Optimización móvil.

### Etapa 4
Funcionamiento offline.

### Etapa 5
Sincronización automática con Firebase.

### Etapa 6
Seguridad y control de usuarios.

### Etapa 7
Empaquetado APK.

### Etapa 8
Pruebas en dispositivo físico.

## Importante

La aplicación original `index.html` no debe eliminarse durante las primeras etapas.

Los nuevos componentes se agregan progresivamente para evitar perder la versión funcional actual.
